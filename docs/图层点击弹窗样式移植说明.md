# 图层点击弹窗样式 —— 移植说明

> 适用前提：目标项目使用 **ArcGIS JS API 3.x**，弹窗用内置的 `map.infoWindow`（其 DOM 根类名是 `.esriPopup`）。
> 范围：只迁弹窗的**深色科技风样式**（外壳 + 内部属性表格），不含取数/高亮等逻辑。
> 源文件：[src/assets/styles/ledcss.css](src/assets/styles/ledcss.css)（`.esriPopup` 段）、`SwitchMap.js` 的 `buildGuanwangHtml`。

---

## 一、弹窗外壳样式（.esriPopup）

这段是对 ArcGIS 内置 infoWindow 默认白底的覆写，全部用 `!important` 压过 esri.css：

```css
/* 外壳：透明底 + 青色外发光 */
.esriPopup {
    background: transparent !important;
    box-shadow: 0 0 16px rgba(0, 163, 255, 0.35) !important;
}

/* 标题栏：蓝青渐变 */
.esriPopup .titlePane {
    background: linear-gradient(135deg, rgba(0, 163, 255, 0.95) 0%, rgba(0, 90, 180, 0.9) 60%, rgba(0, 40, 90, 0.95) 100%) !important;
    border-bottom: 1px solid #00caff !important;
    box-shadow: 0 0 12px rgba(0, 202, 255, 0.5) inset !important;
}

/* 右上角最大化/关闭按钮位置微调 */
.esriPopup .titleButton.maximize {
    top: 10px !important;
}

.esriPopup .titleButton {
    top: 6px !important;
}

/* 标题文字 */
.titlePane .title {
    height: 36px;
    font-size: 15px;
    font-weight: bold;
    line-height: 36px;
    padding-left: 14px;
    color: #ffffff;
    letter-spacing: 1px;
    text-shadow: 0 0 8px rgba(0, 202, 255, 0.9);
}

/* 弹窗宽度 */
.esriPopup .sizer {
    width: 360px !important;
}

.esriPopup .sizer .lie1 {
    background: #D8EAFC;
    text-align: center;
    color: #494949;
}

/* 内容面板：深色底 + 青色描边 */
.esriPopup .contentPane {
    max-height: 360px !important;
    background: #031016f5 !important;
    border: 1px solid #00a3ff44 !important;
    border-top: none !important;
}

/* 内容滚动条：细条 + 主题色 */
.esriPopup .contentPane::-webkit-scrollbar {
    width: 4px !important;
}

.esriPopup .contentPane::-webkit-scrollbar-thumb {
    background: var(--popContentHeadbg) !important;
    border-radius: 2px !important;
}

.esriPopup .contentPane::-webkit-scrollbar-track {
    background: transparent !important;
}

/* 弹窗箭头：深色 + 青色描边 */
.esriPopup .pointer {
    background: #031016 !important;
    box-shadow: none !important;
}

.esriPopup .outerPointer {
    background: #00a3ff !important;
    box-shadow: none !important;
}

/* 底部操作栏：透明，去掉白条 */
.esriPopup .actionsPane {
    background: transparent !important;
    border-top: none !important;
    padding: 0 !important;
}
```

## 二、弹窗内容样式（属性表格）

弹窗内容是用 `map.infoWindow.setContent(html)` 塞的一段 HTML，样式写在行内。骨架如下（一个「标题 + 键值表」单元，可复制多段）：

```html
<div style="padding:10px 14px;">
    <!-- 每条记录：标题（青色 + 左侧发光竖条） -->
    <div style="position:relative;font-weight:bold;font-size:14px;color:#00e5ff;margin-bottom:8px;padding-left:10px;text-shadow:0 0 6px rgba(0,229,255,0.6);">
        <span style="position:absolute;left:0;top:2px;bottom:2px;width:3px;background:#00e5ff;box-shadow:0 0 6px #00e5ff;"></span>
        记录标题
    </div>

    <!-- 键值表：左列浅蓝标签，右列白色值 -->
    <table style="border-collapse:collapse;font-size:12px;width:100%;">
        <tr>
            <td style="padding:3px 10px 3px 0;color:#6fb3d0;white-space:nowrap;vertical-align:top;">字段名</td>
            <td style="padding:3px 0;color:#ffffff;word-break:break-all;">字段值</td>
        </tr>
        <!-- 复制 <tr> 拼更多字段 -->
    </table>

    <!-- 多条记录之间加虚线分隔 -->
    <div style="margin:10px 0;border-top:1px dashed #00a3ff55;"></div>
</div>
```

关键颜色：
| 用途 | 颜色 |
|---|---|
| 标题文字 / 左侧竖条 | `#00e5ff`（青） |
| 字段名（标签列） | `#6fb3d0`（浅蓝） |
| 字段值 | `#ffffff`（白） |
| 记录分隔虚线 | `#00a3ff55` |

## 三、依赖清单

| 依赖 | 说明 |
|---|---|
| `var(--popContentHeadbg)` | 滚动条 thumb 的颜色，需在目标主题里定义；默认值 `#00a3ff99`（可直接硬编码替换） |
| ArcGIS JS API 3.x | `.esriPopup` 是 3.x infoWindow 的 DOM，4.x 结构不同 |

---

## 四、迁移步骤

1. **贴外壳样式**：把第一节 CSS 整段贴到目标项目的**全局样式**（不要 scoped，原因见下）。
2. **补变量**：确认 `--popContentHeadbg` 存在；没有就把它替换成 `#00a3ff99` 或你自己的主题色。
3. **贴内容模板**：弹窗内容按第二节 HTML 骨架拼接，字段名/值换成你的数据。
4. **调颜色**：`#00a3ff` / `#00e5ff`（青）、`#031016`（深底）按目标主题统一即可。

---

## 五、注意事项

1. **必须在全局样式，不能 scoped**：`.esriPopup` 是 ArcGIS 运行时动态生成到 `#map` 容器里的 DOM，不在你的 Vue 组件模板内，scoped 样式加 `data-v-xxx` 后匹配不到。放在全局 CSS（如本项目 `ledcss.css` 这种被 `import` 进来的普通 css）即可。
2. **弹窗赋值方式**：标题 `map.infoWindow.setTitle("...")`，内容 `map.infoWindow.setContent(html)`，显示 `map.infoWindow.show(screenPoint, anchor)`。
3. **旧版 infoWindow 布局**：`.esriPopup .sizer .lie1` 是 3.x 旧版 sizer 布局里的一个格子，保留无害；如果目标项目用的是新布局，这段可以删。
4. **若目标不是 ArcGIS 3.x**（比如换成了 leaflet / openlayers / 4.x 自定义弹窗）：外壳样式失效，只有第二节的「内容 HTML + 行内样式」能复用，外壳需按目标地图库的弹窗 DOM 重新写。
